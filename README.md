# Digital Marketing Academy

A responsive educational website designed to help beginners learn digital marketing through practical projects.

## 🌐 Live Website

[View Live Website](https://yashs00n.github.io/digital-marketing-academy/)

## 📌 Project Overview

Digital Marketing Academy is a multi-page responsive website that provides information about digital marketing courses, practical learning, and career guidance.

The project includes a landing page with a lead generation form connected to Google Apps Script and Google Sheets.

## 🚀 Features

- Responsive website design
- Multi-page navigation
- Home page
- About page
- Courses page
- Landing page
- Contact page
- Lead generation form
- Form validation
- Google Apps Script integration
- Google Sheets data storage
- Mobile responsive design
